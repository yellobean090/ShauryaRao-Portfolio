⚙ os from scratch
NityaOS

A 32-bit x86 operating system built from scratch in C and NASM assembly — own bootloader handoff, own GDT/IDT with 32 CPU exception handlers and remapped PIC IRQs, a physical memory manager with paging, and a custom heap allocator. Preemptive multitasking is driven directly off the hardware timer, with PS/2 keyboard and mouse drivers, CPUID feature detection, PCI enumeration, and a working Intel e1000 NIC driver that reads the real MAC address off hardware. Boots via GRUB Multiboot into a small windowed GUI with a live shell.

C x86 Assembly NASM GRUB Multiboot QEMU
